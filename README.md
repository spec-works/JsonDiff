# JsonDiff

Software component for generating JSON Patch (RFC 6902) documents by comparing two JSON objects.

## Specification

Implements [RFC 6902](https://datatracker.ietf.org/doc/html/rfc6902) - JavaScript Object Notation (JSON) Patch.

See [specs.json](specs.json) for complete specification references.
